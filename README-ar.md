# خطوات التشغيل (كلها مجانية)

افعلها من الكمبيوتر، فرفع مجلد `.github` أسهل منه.

## 1) بوت تيليجرام
1. افتح @BotFather في تيليجرام، اكتب /newbot واختر اسماً.
2. انسخ **التوكن** الذي يعطيك إياه.
3. افتح بوتك وأرسل له أي رسالة (مثل: hi).
4. افتح في المتصفح: `https://api.telegram.org/botالتوكن/getUpdates` (ضع التوكن مكان الكلمة).
5. ابحث عن `"chat":{"id":` والرقم بعده هو **CHAT_ID**.

## 2) مفتاح Gemini
ادخل https://aistudio.google.com ثم Create API key، وانسخ المفتاح.

## 3) GitHub
1. أنشئ مستودعاً جديداً **عاماً (Public)**.
2. ارفع كل محتويات هذا المجلد، مع مجلد `.github`.
3. Settings ← Secrets and variables ← Actions ← New secret، وأضف ثلاثة:
   - `TELEGRAM_TOKEN`
   - `TELEGRAM_CHAT_ID`
   - `GEMINI_API_KEY`
4. Settings ← Pages ← Source: Deploy from a branch ← main / root. سيظهر رابط موقعك.
5. تبويب Actions ← engine ← Run workflow (للتجربة الأولى).

## 4) الاستخدام
شارك منشوراً أو الصق نصه في البوت. بعد دقائق (حتى 10 أو أكثر) تصلك مسودة مع زرّي **نشر** و**حذف**. بعد النشر يظهر في الموقع عند التشغيل التالي.

## تنبيهات
- ما ترسله للبوت قبل الاعتماد يُحفظ في `state.json` داخل مستودع عام، فلا ترسل ما لا تريد أن يراه الناس.
- تشغيل GitHub قد يتأخر، وقد يوقف الجدولة بعد فترة طويلة بلا نشاط في المستودع.
- إن أُوقف نموذج Gemini، غيّر اسمه بإضافة متغير `GEMINI_MODEL`.
- راجع كل مسودة قبل النشر: الذكاء الاصطناعي قد يخطئ.
